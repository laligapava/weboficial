# La Liga Pava — sitio completo

Landing de La Liga Pava (fútbol 7 amateur) lista para GitHub Pages.

## Estructura
- `index.html` — página principal
- `privacidad-cookies.html` — política de cookies
- `liga-web.js` — interacciones (nav, modales, formularios, animaciones)
- `assets/` — imágenes, ya comprimidas al máximo

## Publicar en GitHub Pages
1. Sube todo este contenido a la raíz de tu repositorio.
2. Settings → Pages → Source: rama `main`, carpeta `/root`.
3. Guarda; la URL pública tarda 1-2 minutos en activarse.

Sin build ni dependencias — HTML/CSS/JS plano, listo tal cual.
